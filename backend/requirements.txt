# Backend runtime dependencies — Termux-friendly on purpose.
#
# Notes:
# - `uvicorn` is intentionally the PLAIN package (not uvicorn[standard]):
#   the [standard] extra pulls uvloop/httptools which often fail to compile
#   on Termux/Android.
# - If `argon2-cffi` or `pillow` fail to build, install native tools first:
#     pkg install clang python-pillow
# - `pkg install ffmpeg` is REQUIRED for video composition on Termux.
# - S3 storage is OPTIONAL: `pip install -r requirements-s3.txt` (boto3 is
#   heavy; the code raises an honest error if the backend is selected without
#   it being installed).
